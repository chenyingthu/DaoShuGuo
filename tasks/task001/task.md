# task001: IEEE33 无功优化最小闭环验证

## 任务目的

本任务用于验证本项目 MVP 的最小自主科研闭环是否可在真实电力仿真上运行：

1. 能否读取明确的任务定义。
2. 能否在 evaluator 驱动下比较候选结果与基线。
3. 能否形成结构化的运行、分级、证据和报告产物。
4. 能否在真实 `pandapower case33bw` 上完成 baseline/candidate 对比。

## 研究对象

IEEE 33 节点配电网无功优化问题。

## 当前目标

在 `pandapower case33bw` 默认工况下，相对基线改善：

- 网损
- 电压偏差

同时不得引入新的约束违反。

## 当前边界

- 仅覆盖单工况
- 仅覆盖单次任务
- 第一轮真实任务采用 `ext_grid.vm_pu` 搜索作为候选 skill
- 当前目标仍然是验证闭环，不追求论文级算法创新

## 本任务在项目中的意义

它不是为了证明方法已经很强，而是为了证明：

- 系统的对象边界是稳定的
- 运行时产物能按 schema 写回
- “成效 -> 品味 -> 报告” 的约束链条已经成立
- baseline 与 candidate 能在真实仿真栈中被统一 evaluator 比较
