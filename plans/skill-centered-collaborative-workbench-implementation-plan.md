Core implementation target:

> Convert the current collaborative workbench from a topic-centered cockpit into a skill-centered research cockpit.

The workbench must show:

1. current active skill
2. candidate skill family
3. method / process / standard changes
4. skill-use vs structural skill judgment
5. evaluator evidence
6. forbidden shortcuts and forbidden claims
7. next skill-worker routing constraints
