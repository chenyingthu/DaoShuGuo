# 科研品味评估框架

## 1. 文档目的

本框架用于把“科研品味”从经验性判断转化为系统中的显式约束、分级器和审核机制。

其核心任务不是帮助系统“写得更像论文”，而是帮助系统判断：

1. 当前成果的真实质地是什么。
2. 允许做出多强的主张。
3. 应该如何表达，才不背离证据。

## 2. 基本原则

- 成果等级由研究材料决定，不由写作能力决定。
- 写作只能提升可理解性，不能提升成果等级。
- 没有稳定证据，不得上升为高等级成果。
- 没有边界分析，不得上升为规律性认知。

## 3. 四级框架

### 3.1 拓玉

定义：

研究成果本身质地极高，核心发现明确、证据扎实、价值显著，表达主要起呈现作用。

特征：

- 结果本身已经很强
- 证据链完整
- 与基线差距明显
- 机理解释可信
- 外部价值高

允许表达：

- 可以使用较强的主张
- 可以强调发现本身的重要性
- 可以写成高等级论文核心结果

风险：

- 误把局部亮点当作全局突破

### 3.2 琢石

定义：

研究成果有明确价值，但必须依靠严谨论证、清晰组织和细致表达，才能显出其真实质量。

特征：

- 结果有料，但不自发显形
- 需要结构化论证
- 需要精心比较与解释
- 机理层面有部分支撑

允许表达：

- 可以形成完整论文或技术报告
- 可以强调方法价值，但必须控制外延

风险：

- 过度包装后误判为“拓玉”

### 3.3 雕木

定义：

研究成果存在一定工作量或局部价值，但材料较薄，主要依赖好的整理、总结和表达，才能保住可取之处。

特征：

- 结果不够硬
- 泛化能力弱
- 支撑材料有限
- 机理解释不足

允许表达：

- 适合写技术报告、工程记录、经验总结
- 不适合强行包装成高等级科研突破

风险：

- 因写作能力强而被误判为“琢石”甚至“拓玉”

### 3.4 绘墨

定义：

缺乏足够研究材料，主要依赖语言组织、概念拼接和修辞制造“像成果的样子”。

特征：

- 结果证据不足
- 对比基线不成立
- 机理解释悬空
- claim 强度明显超过证据

允许表达：

- 只能作为设想、备忘、申请草案、讨论材料
- 不得写成正式科研成果

风险：

- 对团队判断形成严重误导

## 4. 成果分级规则

系统在进入正式写作前，必须完成一次成果定级。

定级至少检查以下维度：

1. 问题价值
2. 基线质量
3. 指标改善幅度
4. 结果稳定性
5. 复现性
6. 机理解释程度
7. 适用边界说明
8. 外部影响潜力

任何高等级结论都不得绕过该步骤。

## 5. Claim 上限规则

系统应根据成果等级限制允许输出的主张强度。

### 5.1 拓玉

允许：

- 明确声称获得强结果
- 强调理论或工程意义

要求：

- 有多维证据支撑
- 有边界和风险说明

### 5.2 琢石

允许：

- 声称方法有效
- 声称在特定条件下具有明显优势

要求：

- 明确限定适用范围
- 不得过度上升为普遍规律

### 5.3 雕木

允许：

- 声称观察到有意义现象
- 声称形成了阶段性方法或经验

要求：

- 必须降低语气
- 不得宣称重大创新

### 5.4 绘墨

允许：

- 只能说“提出设想”或“形成讨论”

要求：

- 必须显式标注证据不足
- 禁止科研成果化包装

## 6. 反绘墨约束

为防止 Agent 因语言能力过强而制造成果幻觉，系统必须具备以下约束：

1. 没有独立 evaluator，不得声称改进成立。
2. 没有强基线比较，不得声称显著优越。
3. 没有稳定复现，不得声称方法可靠。
4. 没有边界分析，不得声称获得规律。
5. 没有证据回链，不得写入稳定认知网络。
6. 写作修辞不得提升成果等级。

## 7. 品味的四类判断

### 7.1 选题品味

关注：

- 问题是否重要
- 是否有真实对象支撑
- 是否能产生有价值资产

### 7.2 成果品味

关注：

- 结果到底多硬
- 是否值得进一步投入
- 是否足以支撑对外传播

### 7.3 机理品味

关注：

- 哪些现象值得抽象为认知
- 哪些只是局部偶然
- 哪些解释只是事后叙述

### 7.4 表达品味

关注：

- 表述是否忠实于证据
- 是否主动控制语气
- 是否诚实暴露不确定性

## 8. 与系统的映射

科研品味评估框架在系统中需要落成三个组件：

1. Taste Grader
2. Claim Guard
3. Report Gate

### 8.1 Taste Grader

输入：

- evaluator 结果
- 基线对比
- 复现情况
- 认知解释

输出：

- 成果等级
- 等级理由
- 风险提示

### 8.2 Claim Guard

功能：

- 检查报告中的 claim 是否超出允许上限
- 对超限内容进行降级或标红

### 8.3 Report Gate

功能：

- 决定该成果应进入哪类文档
- 例如论文草稿、技术报告、实验记录或讨论备忘

## 9. 对 Agent 的明确要求

Agent 在写作前必须先自问：

1. 我手里的是玉、石、木，还是墨。
2. 这些材料支不支撑我要说的话。
3. 我是在发现价值，还是在制造价值幻觉。

如果第三问不能被否定，则必须主动降级表达。

## 10. 核心结论

真正的科研品味，不是把东西说得高级，而是知道什么东西本身已经足够高级，什么东西还不配被说成那样。
