# 持续记录模板

## 1. 用途

本模板用于后续持续记录本项目中的关键实验、讨论和判断变化。

建议每当出现以下情况之一时追加一条记录：

- 新技能实现
- 新认知写回
- 新比较分析完成
- 重要失败出现
- 技术路线发生修正
- 对项目目标的理解发生变化

## 2. 记录模板

```markdown
## 记录 {N} — {YYYY-MM-DD}

### 背景
本次记录对应什么任务、实验或讨论。

### 动作
- 做了什么
- 改了什么
- 跑了什么

### 结果
- 指标如何
- 是否成功
- 是否失败
- 有哪些结构化产物

### 新认知
- 形成了什么理解
- 这条理解基于什么证据
- 它适用在哪里

### 认知变化
- 纠正了什么旧判断
- 强化了什么旧判断
- 哪些地方仍然不确定

### 对框架的启发
- 这一步暴露了框架什么优势
- 暴露了什么缺陷
- 后续应该加什么能力

### 后续问题
- 还没有回答的问题是什么
- 下一步最值得做什么
```

## 3. 记录要求

- 不要只写“做了很多事”，要写“改变了什么理解”
- 不要只写结果，要写边界与不确定性
- 不要只记成功，也要认真记失败
- 要尽量把讨论中的关键判断写下来，而不是只记代码文件

## 4. 推荐记录位置

建议优先追加到：

- [实验过程与讨论记录.md](/home/chenying/root-research/DaoShuGuo-v1/docs/实验过程与讨论记录.md)

如果单次记录较长，也可以单独建：

- `docs/logs/{topic}-{date}.md`

再在主记录文件中做索引。
